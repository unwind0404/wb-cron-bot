# WB Review Bot — панель управления автоответами на отзывы Wildberries

Сайт с панелью управления: добавляйте магазины, выбирайте стратегию ответов, смотрите историю. Бот раз в день отвечает на неотвеченные отзывы.

## Возможности

- 🔐 Вход по паролю администратора
- 🏪 Несколько магазинов: добавление (с проверкой токена), удаление, вкл/выкл
- 🎯 Стратегия ответов на каждый магазин: **Шаблоны** (по звёздам) или **LLM** (умные ответы через ИИ)
- 💬 История обработанных отзывов с ответами бота
- ▶️ Кнопка «Запустить сейчас» — не ждать ежедневного cron
- 📱 Telegram-уведомления (опционально)

## Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Обязательна | Описание |
|---|---|---|
| `ADMIN_PASSWORD` | ✅ | Пароль для входа в панель |
| `SESSION_SECRET` | рекомендуется | Случайная строка для подписи сессий (любая длинная) |
| `CRON_SECRET` | ✅ | Секрет для запуска cron (любая длинная строка) |
| `DATABASE_URL` | ✅ | Postgres (бесплатно: [Neon](https://neon.tech) или Vercel Postgres) |
| `OPENROUTER_API_KEY` | при LLM | Ключ [openrouter.ai](https://openrouter.ai) |
| `LLM_MODEL` | нет | Основная модель (по умолчанию DeepSeek V3 free) |
| `LLM_FALLBACK_MODEL` | нет | Запасная модель (по умолчанию Llama 3.3 70B free) |
| `TEMPLATES_JSON` | нет | Свои шаблоны: `{"5": "текст", ...}` |
| `TG_BOT_TOKEN` | нет | Токен бота от @BotFather (для отчётов) |
| `TG_CHAT_ID` | нет | Ваш chat_id |

`WB_API_TOKEN` больше не нужен — токены магазинов добавляются через панель.

## Настройка БД (5 минут)

1. Зарегистрируйтесь на [neon.tech](https://neon.tech) (бесплатно, без карты)
2. Создайте проект → скопируйте Connection String
3. Вставьте в Vercel как `DATABASE_URL`

Таблицы создаются автоматически при первом запуске.

## Локальная разработка

```bash
npm install
vercel dev
```

## Ручной запуск cron

```bash
curl -X POST https://<проект>.vercel.app/api/cron -H "Authorization: Bearer <CRON_SECRET>"
```

Или кнопкой «Запустить сейчас» в панели.

## Расписание

`0 7 * * *` (07:00 UTC = 10:00 МСК), меняется в `vercel.json`.
